explicit model downloads, permission requests and Stop and finalize. It handles
unsupported systems and missing English assets. Its 187 KB synthetic sample
was created locally using the macOS Samantha voice; see example/README.md.

Native lifecycle fixes:

* Reserve IDs before asynchronous preparation, preventing duplicate startup
  from replacing another request. Pending requests forward cancellation.
* Clean up recognition startup failures; preserve cancellation that arrives
  before a recognition task starts.
* Remove requests before reporting terminal callbacks.
* Copy tap buffers retained by an analyzer instead of retaining reusable
  microphone storage. Surface converter errors through a throwing stream.
* Serialize microphone start/stop; clean up prepared but unstarted capture.
* Restore iOS audio-session category, mode and options after capture. Prior
  active state cannot be inferred; apps managing it should opt out.
* Dart cancellation waits for startup, is idempotent, and doesn't double
  complete `done` when a terminal callback precedes a startup failure.

The Pigeon schema was formatted only; generated messages are unchanged. No
new dependencies or global settings, no commits, no other package source edits.
The root README and docs/CODEX_HANDOFF.md were updated. iOS CocoaPods wiring
and Podfile.lock were generated by the successful build and kept.

## Platform behavior and limits

* Analyzer file transcription works without speech authorization.
* Supported/installed locale queries are a better readiness check than aggregate
  asset status alone: this Mac returned `supported` for a custom English
  SpeechTranscriber even though installedLocales contained en-US and the exact
  transcription passed. Dictation and detector combinations show the same quirk.
* SpeechDetector alone yields a zero-channel/zero-rate native format and can
  trap, so the plugin rejects it. With transcription it ran but yielded no
  separate detector events here.
* Volatile results may contain a whole-phrase attributed run. Final results
  provide word timing/confidence when requested.
* Analyzer `finish()` ends live input; for files/assets it waits through EOF.
  `cancel()` stops without waiting for final results.
* `Speech.cancelAll()` is global cleanup; do not start new work concurrently.
  It closes Dart streams, waits for starting analyses, then cancels remaining
  native requests/downloads. Downloads settle through their installation future.
* Only default microphone capture is bridged; keep one microphone session
  active at a time. iOS apps owning an audio session should pass
  configureAudioSession: false.
* Advanced module swapping/timeline control, arbitrary pushed PCM, styling,
  voice analytics and legacy custom language model training are unbridged.
  README lists the supported surface and rationale.
