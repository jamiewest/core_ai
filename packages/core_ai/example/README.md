# core_ai_example

Runs four small bundled Core AI models on macOS 27 or an iOS 27 device:

* **Affine**: `y = 2x + 1`.
* **Stateful**: a state that stays native and accumulates across runs.
* **Image**: a pixel buffer converted to a tensor.
* **Matmul**: three inputs and two outputs, run directly or encoded on a
  compute stream.

It shows the device's Core AI architecture and compute units, and lets you
switch specialization options.

```sh
flutter run -d macos
flutter test integration_test/core_ai_test.dart -d macos   # plugin, end to end
flutter test integration_test/app_test.dart -d macos       # this app's demos
```

The models are generated by `../tool/models/`.
