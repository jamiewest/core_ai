## 0.1.0

* Initial release: Apple's Image Playground sheet for iOS 18.1+ / macOS 15.1+
  over Pigeon platform channels.
* Text, extracted, image and PencilKit drawing concepts; source images from
  files, encoded bytes or BGRA pixels.
* Allowed and selected styles, personalization, creation variety (26.4),
  creation strategy and requested size (27), with explicit errors for
  options the OS does not support.
* One-use sessions that can be cancelled from Flutter; results as PNG bytes,
  or adaptive image glyph data for emoji.
* Typed errors, handle lifecycle with finalizers, and a testing library for
  fakes.
